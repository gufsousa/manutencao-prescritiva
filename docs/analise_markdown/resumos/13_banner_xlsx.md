# Resumo do Arquivo `data/raw/banner.xlsx`

## Do que se trata

É uma planilha com uma aba chamada `banner`, aparentemente derivada do mesmo conjunto de dados do CSV.

## Conteúdo central

- replica a estrutura geral do dataset principal;
- contém colunas equivalentes às do `banner.csv`;
- parece ter sido produzida para visualização ou compartilhamento tabular.

## Papel no projeto

Pode servir como artefato auxiliar de inspeção manual, mas não deve ser tratado como fonte primária de modelagem sem validação.

## Observações

- a amostra lida apresenta sinais de inconsistência de escala/formatação em várias colunas numéricas;
- para uso analítico, o `banner.csv` aparenta ser mais confiável.
