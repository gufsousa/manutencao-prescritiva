# Resumo do Arquivo `docs/11 - prova prtica.docx`

## Do que se trata

É o documento principal do case prático do processo seletivo. Ele apresenta o problema de negócio, o cenário industrial, o desafio técnico esperado e os critérios de avaliação do projeto.

## Conteúdo central

- contextualiza a evolução de manutenção preditiva para manutenção prescritiva;
- descreve a necessidade de correlacionar novos eventos com dados históricos;
- exige integração com base documental para apoiar recomendações;
- pede construção do pipeline completo da solução;
- sugere apresentação visual dos resultados;
- informa critérios de avaliação como arquitetura, organização, documentação e domínio técnico.

## Papel no projeto

É o documento que define o que a solução precisa entregar. Toda a leitura dos demais arquivos deve ser interpretada à luz deste escopo.

## Observações

- é a referência mais importante do repositório;
- contém o exemplo de JSON de entrada;
- deixa claro que o sistema não deve prescrever soluções para problemas sem documentação cadastrada.
