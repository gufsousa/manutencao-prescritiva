# Resumo do Arquivo `docs/11 - prova prtica.pdf`

## Do que se trata

É a versão em PDF do mesmo case descrito no arquivo `.docx`.

## Conteúdo central

- repete as instruções gerais da prova;
- descreve o contexto de manutenção prescritiva;
- apresenta o cenário do projeto e o desafio proposto;
- informa critérios de avaliação e entrega.

## Papel no projeto

Serve como cópia distribuível ou versão estática do enunciado. Em termos de conteúdo, é redundante em relação ao `.docx`.

## Observações

- pode ser usado como fonte alternativa de leitura;
- para extração e reaproveitamento textual, o `.docx` é mais conveniente.
