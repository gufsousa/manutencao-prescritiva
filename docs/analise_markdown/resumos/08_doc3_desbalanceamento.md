# Resumo do Arquivo `data/raw/Doc3.pdf`

## Do que se trata

É um procedimento para identificação e correção de desbalanceamento em máquinas rotativas.

## Conteúdo central

- define desbalanceamento como diferença entre centro de massa e eixo de rotação;
- apresenta sintomas como vibração radial, ruído, desgaste de rolamentos, afrouxamento e fadiga estrutural;
- lista causas comuns, como acúmulo de material, desgaste, falhas de fabricação e reparos inadequados;
- descreve diagnóstico, análise, correção e validação.

## Papel no projeto

É o principal documento para classes de `desbalanceado`, `desbalanceamento` e derivados.

## Observações

- é importante para uma das famílias de falha mais representadas no CSV;
- pode ajudar a diferenciar vibração por massa desbalanceada versus desalinhamento.
