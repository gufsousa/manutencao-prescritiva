# Resumo do Arquivo `data/raw/Doc1.pdf`

## Do que se trata

É um procedimento para diagnóstico e correção de problemas em rolamentos de máquinas rotativas.

## Conteúdo central

- apresenta objetivo de identificar, diagnosticar, corrigir e validar falhas em rolamentos;
- contextualiza a criticidade dos rolamentos em motores, bombas, ventiladores, compressores e outros ativos;
- introduz componentes do rolamento, como anel interno, anel externo, elementos rolantes, gaiola, vedação e lubrificante;
- sugere ser a referência procedural para falhas relacionadas a `rolamento_inner`, `rolamento_outer`, `rolamento_ball` e combinações.

## Papel no projeto

É a principal base documental para a família de falhas de rolamento, que aparece com grande frequência no dataset.

- o PDF não possui camada de texto extraível;
- o resumo foi montado por inspeção visual da primeira página renderizada.
